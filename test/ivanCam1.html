FFMPEG.WASM · BROWSER LAB Хаб для локальных и IP камер

Подключение локальной web‑камеры через getUserMedia и удалённых IP‑камер (HTTP / MJPEG / HLS, если это поддерживает браузер). ffmpeg.wasm используется для записи коротких фрагментов и конвертации в MP4 прямо в браузере.

FFmpeg: ещё не загружен

Добавить источник камеры

1) Для локальной web‑камеры выберите тип «Локальная web‑камера (getUserMedia)» — доступ возможен только по HTTPS.
2) Для IP‑камер укажите прямую ссылку на поток, который умеет воспроизводить браузер (например, http(s)://…/video, MJPEG, HLS и т.п.).

Поддерживаются
getUserMedia, <video>, captureStream().
ffmpeg.wasm использует MediaRecorder‑фрагмент для генерации MP4.
ffmpeg.wasm: библиотека загружается лениво. При первом клике по кнопке «10 сек → MP4 (FFmpeg)» для любой камеры ядро FFmpeg подгрузится в память и дальше будет использоваться повторно.
